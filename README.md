# Student Management System

A full-stack **MERN Student Management System** for managing student records through a responsive web application with authentication, CRUD operations, and MongoDB database integration.

## 🚀 Features

* User authentication
* Secure login and registration
* JWT-based authentication
* Student management
* Add student records
* View student records
* Update student information
* Delete student records
* MongoDB database integration
* RESTful API
* Form validation
* Responsive user interface
* Protected routes
